For New Setup (First Time):
───────────────────────────
1. Run: setup_environment.bat (Windows)
   Or follow: REPRODUCTION_GUIDE.md (detailed steps)

2. Configure credentials:
   - Edit .env file
   - Add serviceAccountKey.json

3. Initialize database:
   python scripts/setup_firestore.py --seed=true

4. Deploy indexes:
   python scripts/deploy_indexes.py

5. Start server:
   uvicorn main:app --reload

For Existing Setup (Update Dependencies):
─────────────────────────────────────────
1. Activate virtual environment:
   venv\Scripts\activate

2. Update packages:
   pip install -r requirements.txt --upgrade

3. Verify setup:
   python verify_setup.py

4. Restart server:
   uvicorn main:app --reload
