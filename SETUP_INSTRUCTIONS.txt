================================================================================
  ESSENTIAL FILES YOU NEED
================================================================================

1. serviceAccountKey.json
   - Download from Firebase Console
   - Place in project root directory
   - DO NOT commit to version control

2. .env
   - Copy from .env.example
   - Update these values:
     * FIREBASE_PROJECT_ID
     * CLOUDINARY_CLOUD_NAME
     * CLOUDINARY_API_KEY
     * CLOUDINARY_API_SECRET
     * JWT_SECRET_KEY (generate new secure key)

================================================================================
  STARTING THE APPLICATION
================================================================================

Option 1: Development mode with auto-reload
   uvicorn main:app --reload

Option 2: Production mode
   uvicorn main:app --host 0.0.0.0 --port 8000

Option 3: Custom port
   uvicorn main:app --port 8001

================================================================================
  COMMON ISSUES & SOLUTIONS
================================================================================

Issue: ModuleNotFoundError
Solution: pip install -r requirements.txt

Issue: Firebase connection failed
Solution: Check serviceAccountKey.json and FIREBASE_PROJECT_ID in .env

Issue: Port 8000 already in use
Solution: uvicorn main:app --port 8001

Issue: Pydantic validation errors
Solution: pip install --upgrade pydantic pydantic-settings

Issue: Environment variables not loaded
Solution: Ensure .env file exists and is properly formatted
